Owners who set up AgentLink before 0.3.0 can now switch to Touch ID (or Windows Hello, or a passkey) in the local app (M1-UX-FIRSTRUN-V2-c): every page shows "Switch to Touch ID" until it is done; the switch asks for the backup code once, then one touch. The owner stays the same and the backup code keeps working.
