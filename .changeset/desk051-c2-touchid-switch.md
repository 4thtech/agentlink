In the desktop app, the Touch ID switch guides you: it goes half-way while you type your master code once (the reason is shown), then you touch the sensor and it is fully on; a cancel or a failed touch returns it to off with a plain message. Settings, Test Touch ID and Replace master code now recognise the app's own Touch ID (Windows Hello on Windows). (DESK051-C2)
