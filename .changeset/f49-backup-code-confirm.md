Without Touch ID or Windows Hello set up for approvals, every approval sheet now has one button: Confirm with your backup code. Switching to Touch ID or Windows Hello is a small link, and after a switch fails because this computer can't protect approvals, AgentLink stops suggesting it in that browser and no longer tells you to open Chrome or Edge when you already use them. Backup code fields have Show and Hide, take pasted codes with line breaks or odd spaces, and the backup code screen has a working Copy (with a Copied note or a clear message), a selectable code and Save as file.
