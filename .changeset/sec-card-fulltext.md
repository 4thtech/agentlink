SEC-CARD-FULLTEXT: approval cards show exactly what the request is about, decoded by AgentLink from the stored request: the full message text (inert, never cut; a long text is shown once before Approve), its files and 80-bit check codes. A card whose content cannot be shown offers no Approve. The Touch ID prompt on Mac and the master code step name who and the cost. An approved proof whose files changed since the approval is refused (`FILE_CHANGED`).
