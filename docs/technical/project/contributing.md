## Improving these docs

The pages on this site are Markdown files in [`docs/`](https://github.com/4thtech/agentlink/tree/main/docs) and are published from the repository. Change them with a pull request like any other change; see [MAINTAINING.md](https://github.com/4thtech/agentlink/blob/main/docs/MAINTAINING.md) for the status hints and the vocabulary rules.
