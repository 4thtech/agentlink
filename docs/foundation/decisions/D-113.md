# D-113: Top-up link format

- **Status:** Decided (owner, 21 Oct 2026)
- **Date:** 2026-10-21
- **Specs:** 06, 08
- **Index:** [all decisions](README.md)

## Decision

**Top-up link format.** **Decided by the owner, 2026-10-21** (M1-26-d): "use https://{payHost}/#v=1&a=<agent address>&usd=<suggested amount>, everything in the fragment, usd optional." Reasons: the address and amount sit after `#`, so they never reach the pay host's server or any CDN log (zero access); the link names no network or token, so the default path needs no chain choice or wallet word (D-39, D-40, D-111); `v=1` versions the format so it can change later; `usd` is optional; the suggested amount follows the existing 08 §1 rule (the shortfall rounded up to the first preset, at least the minimum), which is not part of the owner's decision. `{payHost}` comes from the shipped config, never from inbound content. Spec: 08 §1; 06 §2.1 (`topUpUrl`), §2.4 (`needs_credits`); `docs/design/topup-ux.md` §5. Cards M1-26-d (done), M1-26-e.
