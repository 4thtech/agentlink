## Decision

**M1-7f-2: a receiver-side retention record.** **Decided by Tali in chat, 2026-10-19.** At ingest the receiver's core moves each `fileKey` out of the stored payload into a sealed local `files` row (07 §3: `file_key`, `expires_at`, `deleted_at`); when retention triggers, it deletes that row and the sender deletes the object. Relay and owner copies of the envelope still carry the key, so the effective shred is deleting the object (04 §4).
