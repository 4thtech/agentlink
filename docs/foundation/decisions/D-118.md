## Decision

**The local UI is a React app in `apps/local-ui`, embedded in the CLI.** **Decided by Tali in chat, 2026-10-22:** "Confirmed: option 1, apps/local-ui React app embedded by the CLI." (1) The local UI is a browser-only React app in a new zone `apps/local-ui` (Vite build, uses `packages/ui`). (2) `apps/cli` embeds the built assets and serves them through the existing approval server; `packages/node` stays React-free (deps-check). *Orchestrator plan, not the owner's words:* (3) owner presence and signing stay server-side and the browser never signs; every mutating local-UI route is declared presence-gated and gated centrally, not per handler. (4) Approvals stay on the existing page until M1-11b-2 switches `/` to the new app. Cards: M1-11s-a, M1-11s-b, M1-11r-a, M1-11r-b, M1-11r-c, M1-35c-b, M1-35b-b…d, M1-11b-1…5, M1-11c-a1…a6, M1-11c-a1b, a4b, a5b, M1-11c-b, M1-11c-c.
