# D-19: OCC v2 contracts live in a separate private repo `4thtech/occ-v2-contracts`

- **Status:** Decided (12 Oct 2026)
- **Date:** 2026-10-12
- **Specs:** none
- **Index:** [all decisions](README.md)

## Decision

OCC v2 contracts live in a separate private repo `4thtech/occ-v2-contracts`; the public monorepo consumes only the ABI package `occ-v2-abi` (private and in-repo, never published: amended by D-83) and the shared test vectors
