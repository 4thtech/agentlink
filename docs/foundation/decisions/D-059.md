## Decision

**Contract roles and delays (G-3).** OZ `AccessManager` with the role map in 05 §5.1. (1) **7-day delays** for every contract upgrade, module registration and `ADMIN_ROLE` (a module can charge any payer, so users need time to withdraw and revoke approvals); removing a module is immediate. (2) `PAUSE_ADMIN` administers `GUARDIAN` (cancel only). (3) **Two dedicated ops hardware keys**, Tali's and Denis's, each holding `PAUSER` and `GUARDIAN` for on-call coverage; neither is a Safe-signer device. Denis to confirm before M3 (the Denis pause key). (4) A **2-of-3 testnet Safe** with 1 h / 4 h delays (same role IDs and selector map). (5) A **paused mainnet launch**: contracts start paused and unpause only after the role check passes and every delay is in effect (role check, delays, unpause, smoke test). (6) **Accepted residual risk:** pause cannot stop an integrator withdrawing a balance inflated by a bug, because pause never blocks `withdraw`, `withdrawIntegrator`, `sweep` or the Registry `revoke` (G-39); **M3-1 audit scope must cover this**. Confirmed by Tali (owner's merge of #11, 2026-10-14; stated in chat)
