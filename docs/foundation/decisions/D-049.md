# D-49: One-click consumer storage connectors

- **Status:** Decided (13 Oct 2026)
- **Date:** 2026-10-13
- **Specs:** 07
- **Index:** [all decisions](README.md)

## Decision

**One-click consumer storage connectors** (Google Drive, Dropbox, OneDrive) as the optional own-storage path, delivered in the M2 desktop apps. "Connect" signs in with the provider over OAuth (PKCE, loopback redirect in the desktop app) with minimal scopes (an app folder or app-created files only). Files are stored only as AgentLink ciphertext, with random names, in a dedicated app folder; the recipient downloads through a time-limited share link created by the sender's agent. OAuth tokens stay on the device in the OS keychain and never reach 4thTech (I-1, I-2, I-3 hold); registering the OAuth clients with each provider is an owner action. S3-compatible storage stays the Advanced option, and the cloud self-host template keeps creating an R2 bucket in the user's own Cloudflare account. Local disk is never the transfer point (the recipient may fetch while the sender is offline); local copies of sent and received files stay on the device. **Amends D-18 for connectors:** links on the drop and on S3-compatible storage expire after at most 7 days; with a connector the sender's agent creates the share link, then deletes the object and revokes the link at expiry or on receipt (per `files.deleteAfter`). The provider cannot always enforce link expiry, so this is best effort; the content stays encrypted. `DECISION NEEDED (owner)`: providers that cannot give an expiring public link, and a provider whose sharing API needs a broader scope (07 §5.5)
