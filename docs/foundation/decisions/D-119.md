# D-119: Owner-signed policy loosening is allowed, with warnings the owner must acknowledge

- **Status:** Decided (owner, 22 Oct 2026)
- **Date:** 2026-10-22
- **Specs:** 04, 08
- **Index:** [all decisions](README.md)

## Decision

**Owner-signed policy loosening is allowed, with warnings the owner must acknowledge.** **Decided by Tali in chat, 2026-10-22:** "Yes: owner-signed loosening allowed with warnings, and the UI must not sign until every warning is acknowledged." *Orchestrator wording, not the owner's words:* (1) `preparePolicyEdit` returns stable warning codes for a loosening edit; the warnings are not a hard block. (2) The local UI server refuses to sign a policy edit until the owner has acknowledged every warning code on the confirm screen (cards M1-11c-a3 and M1-11c-a5). (3) Anything the strict policy schema already forbids, for example `allowKeyDisclosure`, stays impossible; no warning acknowledgement unlocks it. Spec: 04 §2.5; 08 §1.
