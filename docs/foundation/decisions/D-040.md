# D-40: Zero-config multi-chain

- **Status:** Decided (12 Oct 2026)
- **Date:** 2026-10-12
- **Specs:** none
- **Index:** [all decisions](README.md)

## Decision

**Zero-config multi-chain.** The client ships the supported-chain list, detects where the agent has credits or stablecoin balance, and picks the chain automatically: the default chain if funded, otherwise the cheapest funded one. Top-ups route to the cheapest supported chain. A chain picker appears only under Advanced. Proof packs carry their chain, so verification needs no setup
