## Decision

**G-13: Record kind is set by the core from the payload type.** **Decided by Tali in chat, 2026-10-18 (option a).** Fixed mapping in 05 §3.1: `offer` OFFER, `accept` ACCEPT, `delivery` DELIVERY, `note` NOTE, `file` FILE, `text` and `request` FILE with files else MESSAGE, `reject` MESSAGE. Control, pairing and owner types are refused for notarization (`NOT_NOTARIZABLE`). A recipient checks the kind against the envelope it holds before signing any receipt; a verifier applies the same check (`contentVerified: false` on a mismatch). Kind values 7–255 stay reserved, so the contract and the ABI are unchanged.
