# D-97: `receiptFlags` bit layout

- **Status:** Decided (owner, 19 Oct 2026)
- **Date:** 2026-10-19
- **Specs:** 05, 07
- **Index:** [all decisions](README.md)

## Decision

**`receiptFlags` bit layout.** **Decided by Tali in chat, 2026-10-19.** Receipt type `t` (1 DELIVERED, 2 OPENED, 3 ACCEPTED, 4 REJECTED, 05 §3.1) sets bit `t − 1` of `receiptFlags`, and its time is `receiptAt[t − 1]`; bits 4–7 stay 0 (05 §3.3). Verifiers cross-check the flags against `receiptAt` and report any mismatch as `malformed_record` (07 §8).
