## Decision

**Branch-push CI and local red evidence.** (1) CI runs on branch pushes; pull requests open only after the independent review passes, already carrying the `IR-…` line; task claims live on the sync board (merged as #17). (2) Tests-first and negative-control red evidence is local: the commit SHA, the exact command and an output excerpt, recorded in the PR; the independent reviewer reproduces it; a failing state is never pushed (`audit-rules.md` §3.4, LL-14). Reason: failed-run e-mails go to the owner's account. Decided by Tali in chat, 2026-10-14
