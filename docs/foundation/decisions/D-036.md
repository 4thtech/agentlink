# D-36: Native desktop apps for macOS, Windows and Linux in M2

- **Status:** Decided (12 Oct 2026)
- **Date:** 2026-10-12
- **Specs:** 11
- **Index:** [all decisions](README.md)

## Decision

**Native desktop apps for macOS, Windows and Linux in M2.** They are signed and auto-updating, built on the same core: a tray app hosting the MCP server, a native approval window with OS biometrics (Touch ID / Windows Hello) gating the owner key in the OS keychain, and harness auto-setup. M1 ships the `npx` package. The framework choice (e.g. Tauri with a Node sidecar vs Electron) is an architecture task with a security review. The local settings and approvals UI design (11 §6.2) becomes the desktop app's UI
