# D-53: MCP tool surface freeze, one-link install-and-pair, J9 as a daily habit

- **Status:** Decided (14 Oct 2026)
- **Date:** 2026-10-14
- **Specs:** 06, 08
- **Index:** [all decisions](README.md)

## Decision

**MCP tool surface freeze, one-link install-and-pair, J9 as a daily habit.** (1) **Tool surface frozen before 0.1.0** (06 §2.0): every tool is prefixed `agentlink_`; 17 tools become 13 (`get_credits` and `fee_quote` fold into `agentlink_status`, `send_message` + `send_file` become `agentlink_send`, `check_inbox` + `get_thread` become `agentlink_inbox`); every tool sets the MCP annotations `readOnlyHint`, `destructiveHint`, `idempotentHint` and `openWorldHint`, so harnesses can auto-allow read-only tools; every tool that can need owner approval accepts and returns `approvalId`. Hints are advisory; policies and approvals stay in the core. I-4 and I-5 are unchanged: no tool changes policies, exports keys, adds storage credentials or bypasses approvals, and inbound content stays wrapped and never appears in descriptions, summaries or errors. (2) **One link installs and pairs** (06 §7.1, 08 §4): `agentlink_create_invite` returns ready-to-send text; the invite page builds an install-and-accept prompt from the link fragment in the browser (the fragment is never sent to a server, and nothing the inviter chose goes into the prompt); the recipient pastes it once into their agent. Diff confirmation, owner setup and the `contacts.acceptInvites` approval are unchanged. (3) **J9 as a daily habit** (02 J9, 06 §6.1): at session start the agent calls the read-only `agentlink_status`, which returns unread counts and contact names only (an owner-set alias, or the other party's name restricted to a safe character set and 32 code points, quoted and with its identity label, falling back to "Contact" plus fingerprint for mixed-script, confusable or label-like names), never inbound text, and has no side effects beyond storing raw envelopes; at session end it offers a handoff only to contacts the user asked to keep in sync, shows the draft and sends only after the user approves that text; an optional SessionStart hook (`agentlink status --brief`) is documented per harness. M1-23 acceptance: the dogfood replaces the personal handoff part of the git sync branch for Tali and Denis
