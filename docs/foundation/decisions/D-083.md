# D-83: G-10: the contracts ABI package is private and in-repo

- **Status:** Decided (owner, 18 Oct 2026)
- **Date:** 2026-10-18
- **Specs:** 05
- **Index:** [all decisions](README.md)

## Decision

**G-10: the contracts ABI package is private and in-repo.** **Decided by Tali, 2026-10-18.** `@4thtech-io/occ-v2-abi` is a private workspace package in this repo (`packages/occ-v2-abi`), built from the ABI JSON, per-chain addresses and SHA-256 manifest that the private contracts repo exports with each tagged release, and the shared vectors. It is bundled into the CLI and is **not published to npm** as a separate package, so no `release.yml` publish step, no `next` prerelease and no npm provenance for it. CI still verifies the imported files against the release manifest and fails if a `.sol` file is present. `@4thtech-io/chain` pins the imported release exactly; Renovate never automerges it. Amends D-19 and supersedes the publish step of 05 §9 (the ABI package is no longer published). The internal rename from `@agentlink/*` to `@4thtech-io/*` is in flight in #250; until it lands the name reads `@agentlink/occ-v2-abi`.
