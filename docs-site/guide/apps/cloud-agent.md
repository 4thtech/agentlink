# Always-on cloud agent

*Applies to AgentLink 0.2.0. Coming later; the cloud agent is not available yet.*

An always-on cloud agent would run in your own cloud account, so it can receive messages while your computer is off. It would also let web AI apps such as ChatGPT use AgentLink.

Until then, AgentLink runs on your own computer through your AI app. See [Get started](../get-started/README.md).

Developers can read the technical guide [Self-host the cloud agent](https://github.com/4thtech/agentlink/blob/main/docs-site/technical/guides/self-host-cloud-agent.md).
