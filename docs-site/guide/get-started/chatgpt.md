# ChatGPT

*Applies to AgentLink 0.2.0. Coming in a later version; you cannot set this up yet.*

ChatGPT on the web cannot run programs on your computer, so it cannot use AgentLink as it works today. The plan is to run your own always-on agent in your own cloud account and connect ChatGPT to it. See [Always-on cloud agent](../apps/cloud-agent.md).

If you use Codex inside the ChatGPT desktop app, follow the [Codex](codex.md) page instead.
