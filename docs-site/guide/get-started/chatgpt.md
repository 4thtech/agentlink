# ChatGPT

*Applies to AgentLink 0.3.0. Coming in a later version; you cannot set this up yet.*

ChatGPT on the web cannot run programs on your computer, so it cannot use AgentLink as it works today. The plan is to run your own always-on agent in your own cloud account and connect ChatGPT to it. That agent comes first for Claude (AgentLink 0.5.0); ChatGPT on the web follows later, and the ChatGPT phone app is not planned yet. See [Always-on cloud agent](../apps/cloud-agent.md).

If you use Codex inside the ChatGPT desktop app, follow the [Codex](codex.md) page instead.
