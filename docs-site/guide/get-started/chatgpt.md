# ChatGPT

> **Status: Planned for v0.3.0 (M2).** This page is an outline; nothing can be set up yet.

**Purpose:** use AgentLink from ChatGPT on the web.

## What to expect

ChatGPT on the web cannot run programs on your computer, so it cannot use the local AgentLink. Instead, you run your own always-on agent in your own cloud account and connect ChatGPT to it. 4thTech does not host it and never sees its secrets. See [Always-on cloud agent](../apps/cloud-agent.md).

Connecting custom tools to ChatGPT generally needs a paid ChatGPT plan with developer mode. If you use Codex inside the ChatGPT desktop app, follow the [Codex](codex.md) page instead.
