- **Where everything lives, with reading paths by role:** [documentation map](https://github.com/4thtech/agentlink/blob/main/docs/README.md)
- **Onboarding for collaborators and their agents:** [onboarding.md](https://github.com/4thtech/agentlink/blob/main/docs/process/onboarding.md)
- **Rules for AI agents working in the repository:** [AGENTS.md](https://github.com/4thtech/agentlink/blob/main/AGENTS.md)
- **Specifications (source of truth):** [docs/foundation](https://github.com/4thtech/agentlink/tree/main/docs/foundation)
- **Task cards:** [backlog.md](https://github.com/4thtech/agentlink/blob/main/docs/process/backlog.md); every change starts from a card
- **Security issues:** never in public issues; see [SECURITY.md](https://github.com/4thtech/agentlink/blob/main/SECURITY.md)
- **Code of conduct:** [CODE_OF_CONDUCT.md](https://github.com/4thtech/agentlink/blob/main/CODE_OF_CONDUCT.md)

## Improving these docs

The pages on this site are Markdown files in [`docs-site/`](https://github.com/4thtech/agentlink/tree/main/docs-site) and are published from the repository. Change them with a pull request like any other change; see [MAINTAINING.md](https://github.com/4thtech/agentlink/blob/main/docs-site/MAINTAINING.md) for the status hints and the vocabulary rules.
