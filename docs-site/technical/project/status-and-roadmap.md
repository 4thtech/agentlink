## Where we are

<!-- status-summary:start -->
**Phase:** M0 Foundations nearly complete; M1a (walking skeleton) released as v0.1.0 on 16 Oct 2026, updated in v0.1.1 and v0.1.2; M1b (files, proof, credits) released as v0.2.0 (pre-alpha, test networks only); the local app is released in 0.3.0 (26 Oct 2026). The repository [README](https://github.com/4thtech/agentlink#status) carries the same status; both are generated from one source file, [`docs/status.yaml`](https://github.com/4thtech/agentlink/blob/main/docs/status.yaml).

**Not yet:** adding real credits from the local app (adding test credits by QR code and a Withdraw button under Advanced are in the local app), backup and restore commands, the owner console, desktop apps and the cloud agent. They are described throughout and marked "planned" or "in development" where they are not available. Proof works on test networks only. v0.3.0 (the `@4thtech-io/agentlink` CLI and MCP server, pre-alpha) is the npm `latest`; install it with `npx -y @4thtech-io/agentlink init`. The local app pages are in 0.3.0 and are not in v0.2.0.

**Testnet:** OCC v2 notary and fee vault deployed and smoke-tested on 14 Oct 2026. Pre-audit. The live submitter records proofs here (21 Oct 2026). Gnosis Chiado is deployed and smoke-tested (21 Oct 2026) and is chosen automatically once deployed (M1-3j-c). **Mainnet:** After the external audit (M3). Not deployed. **Services:** The encrypted drop Worker is deployed to production at drop.agentlink.4thtech.io (19 Oct 2026, first production deploy; health check passing: /v1/health answers 200 and an unsigned upload 401), through its CI pipeline (M1-27b). The released CLI uses it for files above about 12 KB (since v0.2.0). The submitter Worker is deployed to production at submit.agentlink.4thtech.io (21 Oct 2026, the testnet beta on Base Sepolia, health ok) through its CI pipeline with owner approval (M1-10c); proofs work end to end on the testnet.

**In progress:** v0.3.0 is on npm `latest` and a GitHub release (26 Oct 2026; v0.2.0 is the one before it). **In 0.3.0:** the local app is in. `agentlink ui` opens it in your browser; `init` opens the first-run page, where one Touch ID or passkey protects your approvals, sets up your agent and allows the `~/AgentLink/Send` folder, then shows your backup code once; while no owner exists, your AI app opens that page once each time it starts AgentLink. The Activity, Proofs and credits, Contacts, Files and Rules pages are in it. Also merged: the terminal approve card shows a plain summary and no link, agents set up earlier get the Send folder with one command, and allowed folders are pinned so a swapped folder is caught. Still open from M1a: the two-person dogfood between Tali and Denis (M1-23).

**Next:** 0.4.0 is the release now being prepared (Messages, Files, Touch ID upgrade, payment confirmation, status bar, duplicate contacts). The cloud agent follows as 0.5.0 (planned). Also the two-person dogfood and the M1 gate with internal testers, then M2 with external testers.

## Gates

- **M1a:** the two lead developers' agents pair and sync project status through AgentLink, and complete a negotiation over Talk without on-chain proof.
- **M1:** 10 internal testers on at least 3 harness combinations complete install, first message, notarized handover, approvals, verification and a proof of agreement on testnets; no crypto vocabulary in default flows; install to first message under 5 minutes.
- **M2:** 20 to 50 external testers on testnets; the same UX bar, including the desktop apps and the browser counterparty.
- **M3:** first paid notarizations; zero security incidents; an external audit of the contracts with all high and medium findings fixed.

## Not in the beta

A human chat app, real-time chat, readable file hosting or archiving, custody of funds or keys, a project token, payments between parties (later), and forward secrecy for archived messages.
