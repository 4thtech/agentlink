# Public documentation (source)

This folder is the source of AgentLink's public documentation, published on GitBook through Git Sync. It is separate from [`docs/`](../docs/README.md), which holds the internal specifications, process and runbooks.

| Folder | Published as |
|---|---|
| [`guide/`](guide/README.md) | **User guide**: what AgentLink is and how to use it, in plain words |
| [`technical/`](technical/README.md) | **Technical docs**: architecture, protocol, reference, guides and project status |

How the docs are organised, published and kept up to date: [MAINTAINING.md](MAINTAINING.md).

Nothing here describes a feature as available before it is released. AgentLink is pre-alpha: concept pages describe the design, and every other page is an outline marked **Planned** with the version where it gets filled in.
