AgentLink: how to open it the first time
========================================

This early preview of AgentLink is not signed by Apple yet. The first time you
open it, your Mac asks you to allow it once. After that it opens like any other app.

1. Drag AgentLink to the Applications folder (in this window).
2. Open AgentLink from Applications. macOS says it cannot check the app.
   Click "Done" (not "Move to Trash", called "Move to Bin" in some regions).
3. Allow it once:
   - macOS 15 or newer: open System Settings, then Privacy & Security.
     Scroll down to the message about AgentLink and click "Open Anyway".
     A dialog asks again: click "Open Anyway" there too, then enter your
     Mac password or use Touch ID when asked.
   - macOS 13 or 14: in Applications, hold Control and click AgentLink
     (or right-click it), choose "Open", then click "Open" again.

If an older AgentLink is still open, AgentLink tells you. Quit the older one
from the AgentLink icon in the menu bar, then open AgentLink again.

If macOS says "AgentLink.app is damaged": the app is not damaged; macOS says
this about some unsigned downloads. Check the download first (below). Then
click "Cancel", open Terminal and run this one line, which removes the
download mark from AgentLink only, so macOS no longer asks about it:

    xattr -dr com.apple.quarantine /Applications/AgentLink.app

Then open AgentLink again. Do this only for an AgentLink you downloaded from
the address below and checked.

Check the download (recommended while builds are unsigned)
----------------------------------------------------------
Each release lists the SHA-256 of every file in SHA256SUMS-desktop-app.txt,
next to the download. In Terminal, run:

    shasum -a 256 ~/Downloads/AgentLink-*-mac-*.dmg

and compare the result with the line for the same file name in
SHA256SUMS-desktop-app.txt. If you have the GitHub command line tool, you
can also run: gh attestation verify <the .dmg file> --repo 4thtech/agentlink

Download AgentLink only from https://github.com/4thtech/agentlink/releases
More help: https://github.com/4thtech/agentlink/blob/main/docs-site/guide/apps/desktop-app.md
