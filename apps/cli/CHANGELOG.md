- 8b13479: Free test credits finish the proof in the same call (M1-36i-c, M1-36f): after a claim that added free test credits, `agentlink_notarize` and `agentlink_send` with `notarize` wait up to 20 seconds for the credits to arrive (reading the agent's credits only) and then try the same proof exactly once more. No second claim and no second retry; if the credits have not arrived in time, the result is the plain `needs_credits` one. `needs_credits` now says the price and the amount missing in dollars, and `agentlink credits` drops "network" and "public record" from its output.
- 1586cd2: Free test credits on the first proof (M1-36i): when a proof on a test network needs credits, the agent claims free test credits once, through the core's `proofs.requestFaucet` and the submitter's fixed URL, sending only the chain ID and the public agent ID. - 31462cf: While the owner's approval page is open, a tool that needs approval now waits briefly for the owner's decision inside the same call (per harness: Claude Code and Gemini CLI 45 s, Codex 30 s, any other harness no wait). An approval tells the agent to call the tool again now with the approvalId; a denial returns `rejected` with `APPROVAL_DENIED`. A timeout or a client cancel returns the usual `pending_approval` result unchanged (M1-36j).
- ca60f25: When a message network server returns only part of a busy second, your agent now says that some messages may be missing from that check and that it looks again on the next one. Core sync results carry this as an `incomplete` count only (M1-5g).
- 3a08533: Offers and acceptances can now carry proof (M1-9d-3): a firm offer (`agentlink_propose_terms` with `notarize`) and a recorded acceptance (`agentlink_respond_to_terms` `accept` with `notarize`) each need one owner approval that covers the terms and the proof fee, so a proof of agreement can be made and exported through the tools.
- 6055f38: Counter-offers can now carry proof (M1-9d-5): `agentlink_respond_to_terms` `counter` with `notarize` is a firm offer under one owner approval that covers the new terms and the proof fee, as `agentlink_propose_terms` with `notarize`.
