## Decision

**Interim UCD 15.0.0 table for the `terms` character rule (#101).** **Decided by Tali in chat, 2026-10-15.** D-74 requires the General_Category table to be generated from UCD 15.0.0 `DerivedGeneralCategory.txt` with its SHA-256 pinned and a CI drift check. For the M1-21 PR (4thtech/agentlink#101) Tali accepts an interim table generated from CPython 3.12 `unicodedata`, whose Unicode version is 15.0.0, instead of the vendored file. **Required before the M1a release (card M1-21-b, S2):** vendor `DerivedGeneralCategory.txt` with its SHA-256, a lint drift check that regenerates the table from it, and a table-hash vector that every runtime checks. Until then the table's provenance is the interpreter, not a pinned file, so the D-74 drift check does not yet exist.
