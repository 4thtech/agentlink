# D-91: M1-9f: the Claude Desktop extension is an optional bundle built from the npm release

- **Date:** 2026-10-19
- **Specs:** 06
- **Index:** [all decisions](README.md)

## Decision

**M1-9f: the Claude Desktop extension is an optional bundle built from the npm release.** **Decided by Tali in chat, 2026-10-19 (option a).** A self-contained bundle, built by `release.yml` from the npm release and pinned to its version, with a SHA-256 and a build provenance attestation, attached to the GitHub release; signed when the format supports it (beta: self-signed allowed); directory listing at M3. It is an OPTIONAL convenience package for one harness: the product stays harness-agnostic, and every MCP harness uses the same `npx -y @4thtech-io/agentlink` server. Spec in release §2 and 06 §7.
