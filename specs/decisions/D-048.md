# D-48: Encrypted drop by default; own storage optional

- **Status:** Decided (13 Oct 2026)
- **Date:** 2026-10-13
- **Specs:** 04, 06, 12
- **Index:** [all decisions](README.md)

## Decision

**Encrypted drop by default; own storage optional.** Files over 12 KB travel through a 4thTech-operated, zero-knowledge **encrypted drop** (Cloudflare Worker + R2), so file exchange needs no setup. It holds ciphertext only; the file key travels only inside the end-to-end-encrypted envelope, so I-1, I-2 and I-3 hold, and a compromised drop can only deny, delete or delay (integrity: `ciphertextSha256`, `plaintextSha256`). Random 128-bit object keys, no file names; hard 7-day expiry (checked on every download, R2 lifecycle rule as the backstop); retention follows `files.deleteAfter` like any storage (default `expiry`, `receipt` as an owner option), so owners keep access until expiry (I-9); size cap per file (proposed 100 MB) and weekly quota per agent key (proposed 1 GB); every upload signed by a dedicated drop key derived from the agent seed and unlinkable to the agent's public identity (04 §2.1), with quotas and rate limits per drop key and per IP plus a global cap, no accounts; downloads through a signed URL that expires with the object, as with an S3 presigned GET, under the normal SSRF rules; aggregate counters only: no request URLs, signed URLs, object keys or upload signatures in any log, metric or analytics, and platform request logging off in production (I-7; Cloudflare, as the infrastructure operator, still sees request metadata); abuse handled by quotas, expiry and a report path. Own S3-compatible storage is used automatically when configured, and for files above the drop limits, longer retention or a policy that keeps files in own storage (`files.storage`, 06 §3). Files stay free within the quotas; the drop is a 4thTech cost (12 §2). Delivered in M1b with the storage adapter. **Resolves D-13; amends D-05 and principle 5.** `DECISION NEEDED (owner)`: terms of service and takedown process (counsel review); paid larger quotas (later, not now)
