## Decision

**Public docs published continuously from the repository (amends D-29).** The public docs are written in `docs-site/`: a user guide (`docs-site/guide`) and technical docs (`docs-site/technical`), one GitBook space each. Each space syncs from `main` with GitBook Git Sync, GitHub → GitBook only; there is no live editing in GitBook, and every change is a pull request. Docs are published from now on, in parallel with the build, not only when a release deploys: every page carries an honest status line (Design, Planned for vX (Mx), Available since vX, Current), and nothing is marked available before it is released (`docs-site/MAINTAINING.md`). `docs-site/**` is security class S1, so every change gets an independent review; it auto-merges after the orchestrator's audit when the checks are green (D-51, D-52). A milestone or release is done only when its docs pass is done. Any change to the publishing setup (Git Sync, domain, site structure) is owner-only. `DECISION NEEDED (owner)`: a new AgentLink GitBook site or sections in `wiki.4thtech.io`
