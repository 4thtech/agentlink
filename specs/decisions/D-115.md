## Decision

**Own storage and the recovery kit (M1-9i).** **Decided by the owner, 2026-10-21:** "M1-9i: accept all 5 recommendations A–E." Design: `project/design/m1-9i-storage-backup.md` (reviewed, IR-DESIGN-M1-9i-1). (A) The CLI recovery kit (`ALKK` v1) carries full history by default, with an identity-only option. (B) Every export gets a fresh generated recovery code, shown once. (C) Restore never overwrites: an existing agent is refused. *Per the design (IR-DESIGN-M1-9i-1 L1), not the owner's words:* an existing owner is kept only after its own owner code opens it to the kit's owner. (D) Storage credentials are not in the kit; the user reconnects own storage after a restore. (E) Restore signs no owner action; the kit and its recovery code are its authority. Spec text follows in M1-9i-s (04, 06, 07)
