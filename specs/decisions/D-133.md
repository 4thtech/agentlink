## Decision

**Messages and Files In/Out in the local app: read-only, local-only, inbound shown as untrusted plain text.** **Decided by Tali in chat, 2026-10-27** (decision 9; B-11 §18 decisions 1 (a), 4 (a), 5 (a) and 6 (a); design `docs/design/b11-local-app.md` §17 and §18 accepted). (1) A **Messages** page (Inbox and Sent per contact) and **Files** tabs **Received · Sent · Send folders**, Received first. (2) **Read-only:** no compose; "To reply, ask your AI." (3) **Local only:** the pages show what the local agent already holds; nothing new goes to any 4thTech service (zero access). (4) **Inbound content is untrusted plain text** (I-5): message text and other people's file names only inside the untrusted-content container; no Markdown, HTML, images, previews or active links. (5) **No new AI authority** (I-4): read-only `GET` routes on the local page only, no store write, no new or changed MCP tool. (6) Reading in the app **does not mark a message read for the AI**; the page keeps its own "seen" marker. (7) The store records the name a fetched file was saved under in the Inbox folder (sealed, store schema 6), shown as "saved as". **Threat note (author):** the pages read the local store only and return allowlisted fields (never file URLs, file keys, drop links or sealed values); I-4, I-5 and I-7 are unchanged. Spec: 08 §1; 11 §5.7, §6.2.1. Plan: `docs/process/proposals/MSG-FILES-IO.md`. Cards: MSG-FILES-IO-a to -g.
