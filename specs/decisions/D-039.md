# D-39: UX first

- **Status:** Decided (12 Oct 2026)
- **Date:** 2026-10-12
- **Specs:** none
- **Index:** [all decisions](README.md)

## Decision

**UX first.** Users never need a wallet, browser extension, gas, seed phrase or chain choice. Locally there is no login (OS keychain plus desktop biometrics). The console signs in with a passkey (recovery code fallback). The only setup step is adding the MCP to the harness, and the user's own agent can do even that: documented install prompts, `npx @4thtech-io/agentlink init` with harness detection and confirmation, a one-click Claude Desktop extension, and desktop-app auto-setup
