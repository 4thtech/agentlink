# D-43: Versioning framework

- **Status:** Decided (12 Oct 2026)
- **Date:** 2026-10-12
- **Specs:** none
- **Index:** [all decisions](README.md)

## Decision

**Versioning framework** (`project/process/versioning.md`): SemVer 2.0. During beta, all public packages share one product version (Changesets fixed group: CLI/MCP, libraries, later desktop apps), tagged `v<version>` with a GitHub Release. Milestones map to M0 = 0.0.x, M1a = 0.1.0, M1 = 0.2.0, M2 = 0.3.0, M3 mainnet beta = 1.0.0. Prereleases go to npm `next`. Protocol and wire formats are versioned independently with a compatibility table. The spec pack is versioned in the revision history. The root `CHANGELOG.md` uses Keep a Changelog
