## Decision

**Owner decisions of 14 Oct 2026: key commitment (G-46), EIP-7702-delegated agent keys (G-47), owner passphrase minimum, batch gas ceiling, CreateX test fixture.** Decided by Tali in chat, 2026-10-14. (1) **One plaintext for every recipient (G-46):** construction A + D of the decision note `project/process/proposals/G-46-key-commitment.md`, as recommended by its independent review IR-G-46-1 (verdict sound with changes; report private, `4thtech/agentlink-ops`). (A) The payload key `encKey` and a 32-byte key commitment `kc` are derived from the CEK with HKDF-SHA256; `kc` travels in the signed `aead` and is checked before decrypting. (D) Each wrap's HPKE ephemeral key is derived from the CEK, so every opener recomputes the entries it can check, always including its own owner's (04 §3.1, §3.1.1, §3.3). Wire form: `kc` inside `aead`, `alg` `A256GCM-KC`, `v` stays 1. Proof packs: a disclosed key comes with the envelope, and the verifier checks hash, then `sig`, then `kc`, then decrypts and applies the schema (07 §8). The `ct` cap stays 17 152 bytes (worst case 24 563 of 24 576). Different envelopes sent under one `id` to different recipients are recorded as a new gap, G-48. The spec PR gets an independent S2 review, and the M3-1 scope names the derandomised DHKEM ephemeral keys and the `@hpke/core` `ekm` dependency. The review's conditions F-1 to F-4 are written into 04 §3.1.1, §3.3 and 07 §8. (2) **EIP-7702-delegated agent keys (G-47, FA-2):** (a) document the limitation now; (b) add the contract fallback for an EOA whose code is a delegation designator before mainnet (card M1-3l), with the ERC-1271 gas bound required under (b). The gap entry G-47 records it too. (3) **Owner passphrase minimum:** a chosen owner passphrase has at least 12 Unicode code points after NFKC, the same rule as an agent passphrase (04 §2.8). (4) **Batch gas ceiling:** the `notarizeBatch` per-item target in 05 §3.4 goes from 120k to 125k, as recommended by the AUDIT-FABLE-OCCv2-1 re-check, because mixed USDC and native batches had only 158 gas of headroom under 120k; the contracts repo's assertion follows in M1-3k. (5) **CreateX test fixture (D-11):** the contracts repo's test fixture of CreateX's AGPL-3.0 runtime bytecode is acceptable with a licence notice and a `PROVENANCE.md` entry. It is reviewed together with the D-11 / M3-6 source-publication review, as recommended (the recommendation the owner accepted: covered by that review, no separate counsel). No bytecode goes into this public repo
