### Added

- Setup page on first start (M1-11b-8, S2, 06 §7, D-120 (1)): after you install AgentLink and (re)start your AI app, its AgentLink server opens the setup page in your browser once, while this computer has no owner yet, so you can protect approvals with one passkey. Nothing opens when an owner exists, in CI, over SSH or without a display; your AI never sees the page's one-time link, and its tools still tell you which command to run if the page didn't open.
