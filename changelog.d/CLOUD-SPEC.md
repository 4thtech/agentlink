section: Changed
---

- The always-on cloud agent is now planned as AgentLink 0.4.0, right after the usable local app in 0.3.0 (CLOUD-SPEC, S1, D-131; 08 §3, 04 §2.5, §7, §8): it runs in your own Cloudflare account and works first with Claude on the web and in the Claude iPhone and Android apps, with approvals by Face ID or fingerprint on your agent's own page. ChatGPT on the web comes later. The spec records one narrow exception to the crypto rule, for the OAuth library inside your own cloud agent only, which never handles keys or message content.
