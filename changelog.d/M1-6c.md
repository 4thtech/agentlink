- Files that are too large to travel inside a message can go through the 4thTech encrypted drop with no setup (M1-6c, S2, 07 §5.4, §5.6, D-48): the drop receives only encrypted bytes, their size and fingerprint, never the file, its name or its key; links expire within 7 days and are never written to logs. Small files still travel inside the message first, and when several do not fit together the largest move to storage (G-27). Your own storage, when set up, is used instead and never silently swapped for the drop; a busy drop asks you to try again later instead of asking you to set up storage. Using this for sending files comes with the file tools.
