- Large files are encrypted on the fly as they upload to your own S3-compatible storage, and decrypted on the fly as they download, so a large file never has to fit in memory (M1-6b part 2, S2, 07 §5.2, 04 §4): every file gets its own fresh key; a download stops as soon as it is larger than the file it claims to be; and a downloaded file appears only once all of it has been checked, so a damaged or tampered download never leaves a partial file behind. Using this for sending and receiving files comes with the storage selection and file tools.
