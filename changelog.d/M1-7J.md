- When an ID's message servers change (a new list, a reset to the automatic servers or "Update your contact details"), every server that leaves the list is still read for 30 days from that change, each with its own end, so nothing a contact sent there before it learned the new details is lost. Changes can follow each other without waiting; at most 16 servers are kept readable this way, and a change that would need more is refused with the date from which it fits. Only contact-detail updates are sent to those servers, never other messages. The owner's devices are told about every new card, re-told every 24 hours while a leaving server is still read, and every 7 days otherwise. A restore from a backup keeps the leaving servers and the announce choice (M1-7j, S2, D-158 (5), 07 §3, §4.3).
