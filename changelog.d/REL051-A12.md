### Added

- Your AI can now read a Markdown plan, code file, JSON or patch a contact sent, even without file access (REL051-A12, S2, 06 §2.3): `agentlink_fetch_file` returns the text of a text file of up to 64 KB inside an untrusted block, after both checks, next to where it was saved. Larger or other files are saved as before.
- Sent files now carry a file type from their extension, and the receiving agent shows the type it works out from the name itself, never the sender's word for it: `plan.md (Markdown, 97 bytes)` (REL051-A12, 06 §2.2).

### Fixed

- `agentlink_inbox` now shows where each received file was saved (`savedTo`), including files saved automatically (REL051-A12, 06 §2.2): the field was specified but never filled.
