- `agentlink owner init` and `agentlink owner add-agent` set your agent's first rule in the same owner code entry as its card (M1-36b-2, S2, owner decision D6 of 22 Oct 2026; 04 §2.5, §2.8; 06 §3): an empty `AgentLink/Send` folder in your home folder that your AI can send files from. It is created (readable only by you) when missing; an existing folder is used only when it is a real, empty folder, so no existing file becomes sendable. Everything else stays at the defaults, and AgentLink signs nothing wider, whatever was prepared. If the rule can't be set, setup still finishes with the defaults and the folder it created is removed; remove the folder from your rules any time with `agentlink policy remove-folder <path>`.
