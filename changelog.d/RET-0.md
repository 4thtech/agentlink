section: Changed

- Spec for managing history on this computer (RET-0, D-148, S2; 04 §4.2, 06 §3, 07 §3.8, 08 §1, 11 §5.7): Archive hides a conversation, Delete removes it from this computer only (your contact keeps their copy and is not told), saved files go to the Trash only if unchanged, proofs stay valid, and a new "Keep messages" and "Keep saved files" rule is set only by you in the app. 0.5.1 adds a read-only Storage view; deleting arrives in 0.5.2.
