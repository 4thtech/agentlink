- CLI (M1-9z, S2, 04 §2.8): `agentlink owner change-code` † replaces an exposed owner code with a new generated one. It asks for the current owner code (three tries), shows the new code once and asks for its last four characters, then re-wraps the same owner key: the owner fingerprint and every agent card stay valid. The new wrap is staged and checked before the saved owner key is replaced, so a failure leaves the current code working. Refused in a terminal an AI app controls; a recovery kit is not changed.
