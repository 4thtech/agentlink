### Added

- `agentlink policy allow-send-folder` † (M1-36b-2-c, S2, D-121 D6; 04 §2.5, 06 §3, §8): for an agent that was set up before `owner init` and `owner add-agent` signed a first rule, it creates the empty `AgentLink/Send` folder in your home folder (readable only by you; an existing folder only when it is real and empty, never a link) and, with one owner code entry, adds only that folder to your rules. Nothing else in your rules changes, and AgentLink signs nothing wider, whatever was prepared. (Proposed, owner confirms at merge: the 06 §8 wording.)

### Changed

- When your agent tries to send a file and no folder is allowed yet, it now tells you the exact command to run in your own terminal, `policy allow-send-folder` (M1-36b-2-c). Your AI can't set up the folder itself.
- `policy allow-folder` with a path spelled differently from the folder on disk (for example in upper or lower case) shows the exact path and asks `Use <exact path>? (y/N)` instead of refusing; it still allows only the real folder, and a path through a link is still refused (M1-36b-2-c).
