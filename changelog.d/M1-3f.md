### Added

- The contract interface package `@4thtech-io/occ-v2-abi` (M1-3f, S1, D-83, 05 §9): the OCC v2 ABIs and the Base Sepolia testnet addresses from contracts release `v0.1.0-testnet.2`, imported with `tools/occ-v2-abi/import.mjs` and checked in CI against the release's SHA-256 manifest. It is private and bundled into the CLI. Client code gets Notary and vault ABIs without admin, upgrade or module functions, and EIP-3009 deposits stay off until the contracts enable them (M1-3c). Testnet only: no mainnet addresses exist.
- CI fails if any Solidity source (a `.sol` file or a `pragma solidity` line) appears in this repository (M1-3f, D-19).

### Changed

- 05 §7 lists the OpenZeppelin errors and events the deployed contracts can surface, as exported in the ABI (M1-3f, IR-M1-3b-1). The technical docs' Contracts page now explains the interface package and lists the Base Sepolia testnet addresses (M1-3f).
