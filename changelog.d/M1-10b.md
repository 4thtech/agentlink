### Added

- Free test credits, in development and not deployed (M1-10b, S2, 05 §9, 03 §4.4): the submitter can top up a test agent's credits on the test network, so testers never need funds of their own. It serves test networks only, from a fixed list that refuses every main network.

### Security

- The test-credits faucet limits each agent to one claim per day, limits claims and requests per IP, and holds a global daily cap, because new agent identities cost nothing (M1-10b). It uses its own key, separate from the submitter's, and logs no request, IP or agent address.
