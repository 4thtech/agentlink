- Proof-pack verification in the chain client, in development and not user-facing yet (M1-4d, S2, 07 §6.2, §8, 05 §3.3, G-46, D-86): a proof file is checked against the record on the proof network by one record read, the signer's signature (including smart accounts), the disclosed recipient and the recorded receipts, and, when a content key is shared, the message in the fixed 07 §8 order. Every failure has a fixed reason and plain text, and nothing from the proof file or the network address is echoed.
