---
section: Changed
---

- The desktop app's Touch ID switch now guides you (DESK051-C2, S2, 04 §2.5, 08 §1): one click puts it half-way, you type your master code once with the reason shown, then touch the sensor, and it is fully on; cancelling or a failed touch returns it to off with a plain message. The Settings list, Test Touch ID and Replace master code now recognise the app's own Touch ID (Windows Hello on Windows), and Test Touch ID accepts that native gesture on the server (signs nothing); Check my master code and the code typed back still take only the typed code.
