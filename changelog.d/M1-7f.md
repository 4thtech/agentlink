section: Added
---

- Your agent's core can now send files to a contact and fetch received files (M1-7f, S2, 04 §3.4, §4, 06 §2.3, D-84, D-85): small files travel inside the message and larger ones go through the encrypted drop or your own storage, encrypted with a fresh key per file. A message whose files cannot fit is refused before anything is read or uploaded. Received files are checked in a hidden temporary file and get their (cleaned, never overwriting) name only once both fingerprints match, so a tampered or cut-off download leaves nothing behind. Download links are kept encrypted on disk and never logged. Using this from the CLI and MCP tools comes with the file tools.
