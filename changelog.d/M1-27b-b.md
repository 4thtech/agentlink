---
section: Changed
---

- Encrypted drop deploys (M1-27b-b, S2, release-and-deployment.md §4.5.1): the bucket's 7-day deletion rule is now checked before anything is deployed, so a missing rule stops the deploy with nothing changed. A production deploy that is cancelled or times out after it started now always rolls back to the previous version (or confirms that version is still live) and sets the deploy freeze. The drop's CPU limit per request is 5 s instead of 30 s, based on a measured 0.42 s for the largest commit.
