- Owner approvals (M1-8e, S2, 04 §2.3.1, 08 §1): the local approval page on `http://localhost:<port>` can set up a passkey (Touch ID, Face ID or Windows Hello) with one entry of your owner code, and then approve or deny with that passkey instead of typing the code. Your owner code keeps working; a passkey without the PRF feature is not stored. The spec now names where the passkey copy of the owner key lives (`owner-passkey`, one per computer user for now) and the checks on every passkey answer (proposed, owner confirms at merge). The page is not opened by the CLI yet.
