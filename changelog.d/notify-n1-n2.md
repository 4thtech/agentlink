section: Changed
---

- Notices look and behave the same everywhere (N1, N2, S1): errors, the recovery-kit reminder on Settings, and "Copy" buttons now use one shared style, and a new check stops page code from adding its own notice markup. The connection is described in one set of words in the status bar, the top bar and Home. If AgentLink cannot reach the network for more than 5 seconds a notice says so on every page, not only on Home, and "Back online." appears once when it is back. A short blip says nothing.
