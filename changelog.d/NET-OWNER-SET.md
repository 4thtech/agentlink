- Save your own server list (NET-OWNER-SET, S2, D-158, 04 §2.6, 07 §4.3, 08 §1): under Advanced › Message network, the app tests every server you typed again on this computer, adds 2 of AgentLink's automatic servers unless you switch that off (they count toward the 8), and shows a review first: each server and its role, the servers that leave and until when they are still read (30 days each, at most 16, otherwise the date it fits from), how many contacts are told, and any warning. One Touch ID, passkey or master code then signs one new card with exactly that list; contacts get the new details once, and a progress view shows who has them. "Use AgentLink's automatic servers" is the same path back to the defaults. An interrupted change finishes the next time the app opens, with the same list and announce choice. AI apps cannot reach it.
