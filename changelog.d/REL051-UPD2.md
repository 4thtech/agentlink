### Added

- Updates in the browser app (REL051-UPD2, S2, 08 §8): Settings › Updates is now one page for the browser app and the desktop app. It shows your version, a Check for updates button (at most once a minute) and a quiet check once a day. The browser app asks only the npm registry which version of `@4thtech-io/agentlink` is the latest (fixed address, no redirects, nothing about you sent). When a newer one is out, the page says "AgentLink <v> is ready" with the step for how you installed it: "Restart AgentLink to update" for the one-command installer and npx (each start picks the newest), or the one `npm install -g @4thtech-io/agentlink@latest` command with Copy for a global install. Nothing is installed from the page; `AGENTLINK_UPDATE_CHECK=off` turns the check off.
