---
section: Changed
---

- Fewer false "some messages may be missing" notes (M2-19, S1, 07 §4.2): when one message network server returns only part of a busy second, and another server of your agent's list returned that second in full, your agent now asks the first server once for exactly those messages. If it holds them, the note is dropped. The check is strictly bounded (one short question per busy second, at most 64 messages and 16 questions per check) and logs only a count. A second that no other server covers is still reported.
