section: Changed

- The interface package `@4thtech-io/occ-v2-abi` now carries contracts release `v0.1.0-testnet.4` (M3-4b-t-0, S2, D-83, D-89): the Base Sepolia vault accepts the gasless top-up (`depositWithAuthorization`), Gnosis Chiado does not. The function is relay-only: it is in the new submitter ABI `occFeeVaultRelayAbi` and never in the client ABI. `@4thtech-io/chain` pins the release, and a kill switch (`GASLESS_TOPUP_ENABLED = false`) keeps the gasless top-up off everywhere until the owner-approved top-up flow ships (M3-4b-t-4). No change for users yet.
