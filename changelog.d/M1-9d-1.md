- Your agent can send a file and save a received one (M1-9d-1, S2, 06 §2.2, §2.3, 04 §4, D-84): ask it to send a file by its path and it attaches it, but only from a folder you allow in your AgentLink rules; hidden files, private folders and anything outside your allowed folders are refused without being read. Small files travel inside the message, larger ones through the encrypted drop. A new tool saves a received file into your inbox folder only after it arrived complete and unchanged, never replacing a file and never opening it. Your agent never sees download links or file keys. Before most people can use this, two pieces still have to land: a way to allow a folder (`agentlink policy`) and the running encrypted drop for files above about 12 KB.
