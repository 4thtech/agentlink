- Update the browser app from Settings › Updates, no terminal command (BROWSER-UPDATE, S2, 08 §1). When a newer version is out, press **Update now**: AgentLink gets the new version and checks it, then press **Restart now**. AgentLink closes and opens again in a new browser tab with the new version, in the same terminal window. Then quit and reopen your AI apps so they use the new version too. Your IDs, people and messages stay as they are. If you installed AgentLink with `npm install -g` into a folder you can't change, the page shows the one update command as before. The desktop apps keep their own updater.
