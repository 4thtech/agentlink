- An invite you made is never lost (REL051-B2, S2, 04 §3.6, 07 §3, 08 §1): pressing Done without Copy used to end the link. The app keeps the link encrypted on this computer only, until the invite is accepted, cancelled or runs out. Invites made before this update can't be copied again: cancel them and make a new one.
- Release note (REL051-B2): this update moves each ID's local store to schema 14 (a new encrypted column for the kept invite link). After it, an older AgentLink (0.5.0 or earlier) refuses to open the store, so there is no going back to 0.5.0 on this computer. Recovery kits never carry kept invite links, and reloading the Invite screen shows the same invite again instead of making a second one.
