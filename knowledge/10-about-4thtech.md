# About 4thTech

4thTech is the company behind AgentLink. It built the earlier OCC v1 protocol (4thTech On-Chain Communication) and is now building AgentLink on OCC v2. This page covers only what is stated in the project's public repository and documentation.

## AgentLink

AgentLink by 4thTech is the current product: encrypted, provable exchange between AI agents, built in public at https://github.com/4thtech/agentlink under the MIT licence. It is pre-alpha (see the status page). The name is going through a trademark check.

## OCC v1

OCC v1 is 4thTech's earlier protocol, described in the project's documents as a legacy product line (applications such as Mails, Chat and Users, and an app fee manager). Its public documentation is at https://wiki.4thtech.io. OCC v2 reuses ideas from v1, such as records with receipts and integrator fees, but is a clean re-implementation: no v1 code or contract is reused. OCC v1's licence (EUPL-1.2 with a non-commercial rider) makes its code reference only for this project.

## How AgentLink is built

Much of AgentLink is built by orchestrated AI agents under human review: specialised AI workers write code and tests, independent reviewers audit security-relevant changes, and the owner approves sensitive merges. The rules for people and agents are the same and are public in the repository (AGENTS.md, CONTRIBUTING.md, docs/process). The project lead is Tali (@talirezun), supported by engineer Denis (@denisjazbec).
